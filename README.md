# SOC Home Lab

## Objective

Build a Security Operations Center (SOC) home lab using Splunk for monitoring, log analysis, and threat detection.

---

## Technologies Used

- Splunk
- Windows Event Viewer
- Sysmon
- Kali Linux
- AWS
- Python

---

## Skills Demonstrated

- SIEM Monitoring
- Log Analysis
- Threat Detection
- Incident Response
- MITRE ATT&CK Mapping
- Security Monitoring

---

## Lab Architecture

SOC Analyst -> Splunk Server -> Windows Logs -> Threat Detection

---

## Example Detection Use Cases

### Failed Login Detection
Monitor multiple failed logins from the same source.

### PowerShell Abuse Detection
Detect suspicious PowerShell execution activity.

### Privilege Escalation Monitoring
Identify unusual admin account activity.
